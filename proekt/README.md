# Учебный проект заказов

Проект запускается без внешней базы данных: применяется Entity Framework Core InMemory и при старте добавляются тестовые товары и клиент.

## Запуск

```powershell
dotnet restore
dotnet run
```

После запуска доступны главная страница, создание заказа и REST API по адресу `/api/orders`.
