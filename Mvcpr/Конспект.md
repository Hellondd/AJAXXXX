# Загрузка и выдача файлов в ASP.NET Core MVC

Форма отправляет файл методом POST с типом `multipart/form-data`. ASP.NET Core связывает поле формы с `IFormFile`. Для защиты от поддельных запросов форма использует antiforgery-токен.

Перед сохранением нужно проверить наличие файла, размер и допустимый формат. Имени от пользователя доверять нельзя: сервер создаёт новое имя через `Guid`, а файлы кладёт в каталог `Storage` вне `wwwroot`. Поэтому прямой URL не открывает загруженный файл.

Для скачивания отдельное действие проверяет имя и наличие файла, затем возвращает `PhysicalFile` с типом `application/octet-stream`. Здесь ограничение размера составляет 10 МБ, допустимые расширения: TXT, PDF, PNG, JPG. В рабочем сервисе дополнительно проверяют содержимое, права доступа и при необходимости сканируют файл.
