# ASP.NET Core: заявка и анкета

Учебное веб-приложение для дисциплины «Разработка веб-приложений с использованием технологий ASP.NET и AJAX».

## Что реализовано

- форма заявки с проверкой обязательных полей;
- сообщение об успешной отправке;
- отображение заполненной анкеты пользователя.

## Запуск

```powershell
cd StudentApplication
dotnet run
```
